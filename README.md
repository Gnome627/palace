<h1 align="center">Palace</h1>

Панель управления домом для Home Assistant: все устройства — кружками на карте и карточками по зонам.
Клик по кружку включает/выключает устройство, в карточке — яркость, цвет, шторы, климат, громкость.
Изменения в доме (автоматизации, выключатели, другие вкладки) видны сразу; сбой команды страница показывает.
Кружки двигаются, зоны и карточки переставляются, лишнее скрывается, иконки меняются; расстановка
сохраняется кнопкой. Отдельный сервис рядом с HA, ходит в него по websocket с долгосрочным токеном.

## Запуск

Нужны Docker и docker compose.

1. В Home Assistant: профиль → «Безопасность» → «Долгосрочные токены доступа» → создать.
2. Настройки:

   ```bash
   cp .env.example .env
   ```

   В `.env` вписать `HA_URL` и `HA_TOKEN`. `homeassistant.local` внутри контейнера обычно не резолвится —
   пишите IP; если HA на этом же хосте — `http://host.docker.internal:8123`.
   `API_KEY` — ключ для страницы (спросит один раз); пустой — панель открыта всем в сети.
3. Старт:

   ```bash
   docker compose up -d --build
   ```

Страница — `http://<адрес>:8080` (порт на хосте — `PALACE_PORT`). Логи — `docker compose logs -f`.

## Настройки (`.env`)

| Переменная | Что это |
|---|---|
| `HA_URL` | адрес Home Assistant, как его видит контейнер |
| `HA_TOKEN` | долгосрочный токен |
| `API_KEY` | ключ страницы (`X-Api-Key`); пусто — без ключа |
| `IGNORE_AREAS` | id зон через запятую, которые панель не показывает: `router,servers` |
| `IGNORE_ENTITIES` | шаблоны на entity_id целиком, через запятую: `switch.mikrotik_*,sensor.*_rssi` |
| `IGNORE_INTEGRATIONS` | интеграции через запятую — всё, что от них пришло: `mikrotik_router,mobile_app,backup` |
| `PALACE_PORT` | порт на хосте, 8080 |
| `RESYNC_INTERVAL` | полный ресинк реестра, сек (900); между ними всё приходит событиями |
| `CONFIRM_TIMEOUT` | сколько секунд ждать, что HA сообщит об изменении после команды (10); не дождались — предупреждение на странице |
| `LOG_LEVEL` | `INFO` / `DEBUG` |

Если какой-то `IGNORE_*` ничего не скрыл (опечатка, интеграция вписана в `IGNORE_ENTITIES`), при старте в логе будет
предупреждение с подсказкой.

## Расстановка

Положение кружков, порядок зон и карточек, иконки и скрытое хранятся в `palace.yaml` в томе `data`.
Бэкап и перенос:

```bash
docker compose cp palace:/data/palace.yaml ./palace.yaml
```

```bash
docker compose cp ./palace.yaml palace:/data/palace.yaml
```

После заливки — обновить страницу.

## В боковой панели Home Assistant

Настройки → Панели → «Добавить панель» → «Веб-страница», адрес `http://<адрес>:8080`.
Если сам HA открыт по https, браузер не покажет http-страницу внутри него — поставьте Palace за тот же
https-прокси. Ключ во встроенной странице браузер спросит и запомнит отдельно от обычной вкладки.

## Обновление

```bash
git pull && docker compose up -d --build
```

## Язык

Страница по-русски и по-английски (US); выбор — в ленте сверху, запоминается в браузере. По умолчанию — язык браузера.
Все надписи — в `palace/web/locales/<язык>.json`; новый язык — ещё один такой файл и его код в `LOCALES`
(`palace/web/js/i18n.js`).

## Разработка

```bash
python -m venv .venv && .venv/bin/pip install -e ".[dev]"
```

Тесты и линтер:

```bash
.venv/bin/python -m pytest -q && .venv/bin/ruff check .
```

Без Home Assistant — придуманный дом на `http://127.0.0.1:8080`:

```bash
.venv/bin/python scripts/demo.py
```

Страница в настоящем браузере (Chromium в контейнере Playwright, на хосте ничего не нужно), скриншоты — в `browser-check/`:

```bash
tests/browser/run.sh
```
